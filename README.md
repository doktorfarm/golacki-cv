# Krzysztof Gołacki: strona osobista

Wersja do oceny. Strona statyczna (React, Vite, Tailwind), generowana do HTML przy budowaniu.

Podgląd: https://doktorfarm.github.io/golacki-cv/

## Uruchomienie

```bash
npm install
npm run dev       # podgląd na żywo
npm run build     # produkcyjna wersja w dist/
```

## Gdzie co jest

- `src/data.js`: wszystkie teksty, projekty, doświadczenie, FAQ
- `src/components/`: sekcje strony; `Network.jsx` to kula z sercem 3D
- `scripts/images.mjs`: zrzuty z `media/` do AVIF/WebP; `scripts/heart.mjs`: przygotowanie modelu serca (CC0, grab3d.com)

Wersja publikowana tutaj jest ukryta przed wyszukiwarkami i nie zawiera pliku CV.
